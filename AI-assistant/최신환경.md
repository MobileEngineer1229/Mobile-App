# 세계 최신 언어 모형 학습 환경 비교
## 이 프로젝트의 모듈별 실제 리용 현황 및 세계 연구기관 학습 환경

> 작성일: 2026-06-17  
> 기준: 2024~2025년 공개 논문, 기술 보고서, 공식 발표 자료

---

## 1. 핵심 훈련 도구 비교

| 모듈 | 이 프로젝트 | 세계 주요 기관 리용 현황 |
|------|-----------|----------------------|
| **PyTorch** | 모형 훈련 전체 | Meta(개발사), Google DeepMind, OpenAI, Mistral, xAI(Grok), Anthropic — 대부분의 최신 대형 모형이 PyTorch로 훈련됨 |
| **SentencePiece** | BPE 어표 분석기 | Google(LaMDA, T5, Gemma), Meta(LLaMA 1·2·3 전 시리즈), Mistral 7B/8×7B — 산업 표준에 가까움 |
| **numpy + memmap** | 훈련 자료 파일 | nanoGPT(Karpathy), Mistral, Falcon — memmap 기반 자료 처리는 대형 말뭉치에서 표준 방식 |
| **AdamW + cosine LR** | 최적화기 / 학습률 계획 | GPT-4, LLaMA 1·2·3, Gemma 2, Mistral 전부 — 현재 대형 언어 모형의 표준 조합 |
| **TensorBoard / WandB** | 훈련 로그 | Google, Hugging Face, Mistral, Anthropic — PyTorch와 함께 가장 많이 쓰이는 학습 감시 도구 |
| **FlashAttention** | 주의 기제 계산 | Meta(LLaMA 3), Mistral, Anthropic(Claude 3), Together AI — 표준 구현 대비 최대 8배 빠름 |
| **bfloat16** | 혼합 정밀도 | Google TPU 표준, NVIDIA A100/H100/H200/B100, AMD MI300X — 훈련 안정성과 속도 모두 우수 |

## 2. 구조적 설계 선택 비교

| 설계 | 이 프로젝트 | 세계 표준 여부 |
|------|-----------|--------------|
| **디코더 전용 GPT 구조** | ✓ | GPT-2/3/4, LLaMA 1/2/3, Gemma 1/2, Mistral, Falcon, Qwen, DeepSeek 전부 동일 구조 |
| **사전정규화 (Pre-Norm)** | ✓ | GPT-2(2019) 이후 사실상 표준. LLaMA, Mistral 모두 채택 |
| **GELU 활성화 함수** | ✓ | GPT-3, LLaMA 1 채택. LLaMA 2/3는 SwiGLU로 전환 (더 성능 좋음) |
| **가중치 공유 (tie_weights)** | ✓ | GPT-2 채택. LLaMA 2/3는 미채택 (어휘 크기가 커서 분리가 유리) |
| **FlashAttention 자동 적용** | ✓ (`scaled_dot_product_attention`) | Meta, Mistral, Anthropic, Together AI 모두 FlashAttention 2/3 사용 |
| **bfloat16 혼합 정밀도** | ✓ | Google TPU 표준, A100/H100/RTX 30xx+ 표준 |
| **기울기 누적** | ✓ | 현현기억기가 부족할 때 전 세계 모든 팀이 쓰는 방법 |
| **코사인 학습률 감쇠** | ✓ | GPT-3, LLaMA, Gemma — 표준. 최근에는 WSD(Warmup-Stable-Decay)도 증가 추세 |

## 3. 세계 주요 연구기관별 학습 환경 상세

### 3-1. Meta — LLaMA 3 (2024)

**출처:** *"The Llama 3 Herd of Models"* (Meta AI, 2024)

```
모형 규모:   8B, 70B, 405B 매개변수
훈련 자료:  15조 어표 (영어 중심 다국어)
하드웨어:   NVIDIA H100 80GB GPU × 16,384장
            GPU간 연결: InfiniBand + RoCE 망
            전력 소비: 약 39 메가와트
훈련 시간:  405B 모형 = H100 × 16,384장으로 54일
프레임워크: PyTorch 2.x + FSDP (Fully Sharded Data Parallel)
어표 분석기: SentencePiece BPE → Tiktoken으로 전환 (vocab 128,256)
주의 기제:  GQA (Grouped Query Attention) — 추론 속도 향상
활성화 함수: SwiGLU (GELU 대신)
위치 인코딩: RoPE (Rotary Position Embedding) — 학습 위치 임베딩 대신
```

**이 프로젝트와의 차이:**
- 단순 자기 주의 → GQA (KV 캐시 절약)
- 학습된 위치 임베딩 → RoPE (더 긴 문맥 처리 가능)
- GELU → SwiGLU (성능 향상)

---

### 3-2. Google DeepMind — Gemma 2 (2024)

**출처:** *"Gemma 2: Improving Open Language Models at a Practical Size"* (Google DeepMind, 2024)

```
모형 규모:   2B, 9B, 27B 매개변수
훈련 자료:  2B 모형: 2조 어표 / 27B 모형: 13조 어표
하드웨어:   Google TPU v5p (자체 개발 칩)
프레임워크: JAX + XLA (PyTorch가 아닌 Google 자체 프레임워크)
어표 분석기: SentencePiece (256,000 어휘)
주의 기제:  Local Attention (슬라이딩 창) + Global Attention 교대
활성화 함수: GeGLU (GELU의 게이트 변형)
지식 증류:  큰 모형(27B)이 작은 모형(2B, 9B) 훈련에 교사 역할
```

**특이 사항:**
- Google은 TPU를 직접 설계하여 사용 → PyTorch 대신 JAX
- TPU v5p: 칩당 460 TFLOPS (H100의 약 1.7배)
- 지식 증류(Knowledge Distillation): 큰 모형의 확률 분포를 작은 모형이 학습

### 3-3. Mistral AI — Mixtral 8×7B (2024)

**출처:** *"Mixtral of Experts"* (Mistral AI, 2024)

```
모형 구조:   MoE (Mixture of Experts) — 8개 전문가 망 중 2개만 활성화
실제 매개변수: 46.7B (활성화 매개변수: 12.9B)
훈련 자료:  다국어 (영어, 프랑스어, 독어, 이탈리아어, 스페인어)
하드웨어:   NVIDIA H100 클러스터
프레임워크: PyTorch + Megablocks (MoE 특화)
어표 분석기: SentencePiece (32,000 어휘)
주의 기제:  GQA + Sliding Window Attention (문맥 4,096 → 실효 128K)
```

**MoE 구조의 장점:**
```
일반 밀집 모형:  모든 46.7B 매개변수가 매 어표 처리에 관여
MoE 모형:       46.7B 중 12.9B(28%)만 활성화 → 계산량이 훨씬 적음
결과:           GPT-3.5 수준 성능을 GPT-3.5보다 6배 빠른 속도로 달성
```

## 5. 이 프로젝트에 없는 세계 표준 기술 (향후 추가 가능)

### 5-1. RoPE (Rotary Position Embedding)
학습된 위치 임베딩 대신 수학적 회전 행렬로 위치를 인코딩.
LLaMA 2/3, Mistral, Gemma 2, DeepSeek 모두 채택.
**장점:** 훈련보다 긴 문맥도 처리 가능 (외삽 가능성).

### 5-2. GQA (Grouped Query Attention)
8개 머리 모두 별도의 K, V를 갖는 대신, 여러 머리가 K, V를 공유.
LLaMA 2 70B, LLaMA 3 전 시리즈, Mistral 채택.
**장점:** 추론 시 KV 캐시가 줄어들어 더 긴 대화 가능.

### 5-3. SwiGLU 활성화 함수
GELU 대신 스위시(Swish)와 게이트(GLU)를 결합한 함수.
LLaMA 2/3, PaLM, Gemma 채택.
**장점:** 같은 매개변수 수에서 GELU보다 성능 좋음.

### 5-4. MoE (Mixture of Experts)
전달 망을 여러 개 "전문가"로 나누고 매 어표마다 일부만 활성화.
Mixtral, DeepSeek-V2/V3, GPT-4(추정) 채택.
**장점:** 매개변수를 늘려도 계산량이 비례해 늘지 않음.

### 5-5. 분산 훈련 프레임워크
단일 GPU로 훈련할 수 없는 규모에서 필요:

| 프레임워크 | 개발사 | 방식 |
|-----------|-------|------|
| **FSDP** | Meta/PyTorch | 매개변수를 GPU들에 분산 |
| **DeepSpeed** | Microsoft | ZeRO 최적화 (기울기/최적화기 분산) |
| **Megatron-LM** | NVIDIA | 텐서/파이프라인 병렬화 |
| **JAX + XLA** | Google | TPU 특화 컴파일 |

### 5-6. FP8 훈련 (DeepSeek-V3)
bfloat16(16비트)보다 더 낮은 8비트 정밀도로 훈련.
NVIDIA H100/H800의 FP8 텐서 코어 활용.
**장점:** 현현기억기 절약 + 계산 속도 향상.

## 6. 어표 분석기 발전 동향

| 세대 | 방식 | 리용 모형 | 어휘 크기 |
|------|------|---------|---------|
| 1세대 | SentencePiece BPE | LLaMA 1, Mistral 7B | 32,000 |
| 2세대 | Tiktoken BPE | GPT-4, LLaMA 3 | 128,256 |
| 현재 | SentencePiece BPE | DeepSeek-V3, Gemma 2 | 100,000~256,000 |

**이 프로젝트:** SentencePiece BPE, 어휘 크기 16,384 (조선말 특화 소규모)

어휘가 클수록 한 어표가 더 많은 글자를 포함 → 같은 문장을 더 적은 어표로 표현 가능.

## 7. 결론

```
구조와 도구는 세계 표준 그대로다. 규모만 다르다.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 프로젝트가 쓰는 것:                세계 표준과 일치 여부:
  PyTorch                             ✓ 세계 표준
  SentencePiece BPE                   ✓ 세계 표준 (일부는 Tiktoken으로 전환)
  AdamW + 코사인 감쇠                 ✓ 세계 표준
  GPT 디코더 전용 구조                ✓ 세계 표준
  사전정규화 (Pre-Norm)               ✓ 세계 표준
  FlashAttention (자동)               ✓ 세계 표준
  bfloat16 혼합 정밀도                ✓ 세계 표준
  기울기 누적                         ✓ 세계 표준
  GELU 활성화 함수                    △ (최신: SwiGLU 선호)
  학습된 위치 임베딩                  △ (최신: RoPE 선호)
  표준 MHA                            △ (최신: GQA 선호)
  단일 GPU 훈련                       × (대형 모형: 수천 GPU 분산 훈련)
```

이 프로젝트의 코드를 이해하면 LLaMA, GPT, Mistral의 훈련 코드도 같은 원리로 읽을 수 있다.
핵심 차이는 구조가 아니라 **규모와 최신 최적화 기법** (RoPE, GQA, SwiGLU, MoE) 이다.
