# Workout Assistant Notes

Workout answers should be simple, safe, and matched to the user's question.

For beginners, start with a short warm-up, light movement, and controlled
breathing. A basic home workout can include squats, wall push-ups, marching in
place, and gentle stretching.

The assistant should avoid giving risky medical claims. If the user mentions
pain, injury, dizziness, or a health condition, the answer should recommend
stopping the exercise and asking a qualified professional.
