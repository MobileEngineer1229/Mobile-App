# Roadmap

## Phase 1: Text Translator

- Build Flutter text translation screen.
- Add Python lab for local model test.
- Download first multilingual translation model.
- Add DPRK glossary and post-edit rules.
- Add phrase-pair quality tests.

## Phase 2: Offline Mobile Text Runtime

- Convert or quantize selected translation model.
- Add Android native inference bridge.
- Add iOS native inference bridge.
- Package model files with the mobile app.

## Phase 3: Voice Translation

- Add audio recording UI.
- Integrate offline ASR.
- Feed transcript into text translator.
- Add optional offline TTS.

## Phase 4: Image Translation

- Add camera/gallery UI.
- Integrate offline OCR.
- Translate OCR blocks.
- Display translated text list.
- Later add image overlay.

## Phase 5: Quality and Personalization

- Add translation history.
- Add user corrections.
- Build glossary update flow from corrections.
- Add DPRK domain-specific phrase packs.
